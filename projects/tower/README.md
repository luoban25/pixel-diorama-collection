# 五层场景楼

把用户已有的真实三维场景放进同一栋建筑，每层一个。按用户后续要求，楼内不放沙漠与西部列车，也不再用通用住宅、咖啡厅等楼层填充。原来的四个独立项目及其独立页面完整保留。

|---|---|---|
| 01F | 街头篮球 | 完整街区、商店、贩卖机、大树、围栏、像素 X 边缘，六名运动员与四位旁观者，运球、投篮与接球 |
| 02F | 秋日钓鱼池塘 | 原岸线、蓝色池水及反射、秋色树木、码头、两个钓鱼人物、九条游鱼与水波 |

## 打开与操作

打开工作区根目录 `index.html`，点击底部“五层场景楼”；或者直接打开 `scenes/tower/index.html`。独立 HTML 内嵌全部模型、纹理、Three.js 和动画，离线可用。

使用 `?scene=tower&floor=roof` 直接查看屋顶，或者把楼层滑块移到 RF。屋顶默认使用较高的正交视角，切换时平滑过渡；整楼全景和其他楼层仍采用原构图。

- **全景**：查看整栋楼；根据模型投影边界和屏幕大小为控制区留白。
- **楼层**：放大；用右侧滑块选择场景；滚轮一次滑动或按一次上下方向键均只切换一层，鼠标左键/单指拖动用于自由旋转视角。触控板同一滑动的惯性事件不会连续跨层。
- **框架**：隐藏五个场景和装饰，显示实际楼板、梁柱、贯通楼梯。
- **搭建**：自下而上安装结构，再放入原场景和栏杆绿植。再次点击暂停或继续，底部滑块可定位任意搭建阶段。
- **Home**：回全景。遵循系统减少动态效果偏好；减少动画时默认静止，可手动拖动搭建进度。

## 建筑结构

```text
SceneBuilding
├── Foundation：铺装、六组基础墩、花箱
├── Floor[0..4]：y = 0.19 + 楼层序号 × 6.4
│   ├── structure：12.65 × 9.80 厚石材地台、六根连续位置的粗柱、纵横梁
│   ├── interior：一个原始三维场景模块
│   ├── exterior：局部护栏、花盆、自然苔藓、红蓝立管与楼层标牌
│   ├── walls：楼梯侧石墙、真实门洞与铁门
│   └── stairs：红色金属双跑楼梯、各20级、休息平台、楼层平台与扶手
└── Roof：屋顶板、生活露台、水泥小房、设备与植物
```

搭建进度为连续数值 0–6：每层先显示结构，约 57% 时装上侧墙和铁门，约 67% 时放入原场景，约 84% 时加入外部装饰。未开始的楼层实际隐藏。框架视图控制实际分组，而非覆盖一层线稿。相邻楼层共用交接处的平台，十一块楼梯平台各有唯一归属，避免重复面闪烁；通往屋顶的最终平台补齐外侧红色护栏。

## 原项目如何复用

新增的演出现场位于 04F，接在板球场之后；原屋顶露台整体上移 6.4，保持在最上方。`?scene=tower&floor=concert` 可以直接查看第4层。楼层浏览保持屋顶及其支撑结构连续显示，不再在经过演出层时自动切换剖视；各层仍使用现有相机取景。

`src/concert.js` 单独构建第4层：完整舞台桁架与顶棚、两侧竖屏、悬挂阵列音箱、舞台返听、隔离栏、四名乐手、66名观众、6名工作人员、货车及其开启的后门、器材箱、侧棚与调音棚。衣服、肤色和发型有区别，观众面向舞台，按各自不同的间隔与高度错开跳跃，并有起跳蓄力、落地缓冲和非对称挥手；人物保持原来的平面站位。乐手有弹奏、持麦与击鼓动作。六束粉、青、紫、绿、橙和洋红灯光从舞台向观众区扫射，带柔和光斑与局部聚光照明，亮度缓慢变化。观众区上方增加三批六色彩纸礼炮：270片轻量实例纸片错开落下，随风横移、翻转，接近地面时淡出；落区避开舞台顶棚、货车及调音棚，限制在本楼层内。纸片共用一次实例绘制。全部共享十二秒无缝循环，并沿用减少动画设置。演出内容整体按 0.74 的统一比例缩小，使人物、舞台和设备接近下层微缩比例；绿色草坪铺满原有楼板开口，保留周围草地留白。新楼层地台对齐原有楼板开口，人物、树木和桁架均在楼层边界及上层梁底之内。

框架柱截面为 0.76 × 0.76，梁高 0.70，地台厚度 0.64。石材纹理按世界尺寸投影，长柱和长梁不会把图片拉伸成条纹。苔藓采用带噪声、孔隙和柔和边界的局部贴片，分布在石材接缝、柱脚、楼板边缘和管道附近。

右侧墙厚 0.48，每个场景层有一个真实门洞和带铰链、通风百叶、把手的铁门，门槛与红色楼梯平台齐平。屋顶设备房铁门朝向露台，右侧围栏留出 1.58 宽的楼梯入口，入口到铁门之间保留通道。红、蓝两条立管贯通四层，屋顶分别接设备房与水箱，底部转弯接开放管口和排水格栅。

露台以用户的新参考图为依据：米灰色水泥地砖夹杂蓝灰修补砖，两排晾衣绳挂八件衣物，一套木制桌椅，十二个花盆和四组种植箱。周围增加十三组沿围栏生长的像素爬藤；原先穿墙的悬垂立体枝叶已移除，墙面改为三十处无体积的苔藓斑块，贴合实际墙面和女儿墙边界。新植物使用独立随机种子，家具、花盆、衣物与小猫保持原位。小房带雨痕、细裂缝、真实门洞、空调风扇和外墙爬梯，房顶放环箍金属水箱与橘白小猫。衣服随风轻摆、小猫摆尾与呼吸、风扇缓转，均按十二秒循环。旧设备屋顶保存于本地工作区 `versions/tower-before-rooftop-terrace/`，修正前的立体藤蔓保存于 `versions/tower-before-wall-moss/`。

石材来源：[Poly Haven Rock 04](https://polyhaven.com/a/rock_04)，[CC0 许可](https://polyhaven.com/license)。原始下载地址、作者与文件校验值保存在 `assets/stone-source.json`。此次修改前的楼体保存在 `versions/tower-before-stone-frame/`。

`src/projects.js` 创建三个隔离的局部场景，各自有独立材质缓存、原来的随机种子和原动画。构建时直接读取原项目文件，不使用截图、视频或 iframe 冒充楼内模型。

- 篮球：完整读取 `projects/basketball/src/basketball.js` 与 `outfits.js`、`play.js`、`actions.js`。
- 池塘：读取 `projects/pond/src/pond.js`，保留游鱼、钓鱼、波纹、水面着色和局部场景反射。
- 板球：`project-source.cjs` 从 `projects/cricket/src/main.js` 提取原地台、球场、人物与动作，并嵌入原 `environment.js`。

所有动作先在原局部坐标中计算，再应用楼层位移、旋转和统一比例。三个场景保持各自统一比例，地台尺寸与楼板的 11.90 × 9.044 开口对齐；池塘下沉地形嵌入楼板内部，篮球的不规则像素边缘下补上同尺寸地面；篮球的手与球、池塘钓线不会因叠层产生二次位移。三种动画共享12秒循环。

## 主要文件

- `src/building.js`：四层结构、屋顶、原场景安装与搭建状态。
- `src/architecture.js`：粗石框架、红色楼梯、门洞与铁门、自然苔藓、屋顶贯通管道和底部排水口。
- `src/rooftop.js`：生活露台、设备房、铁丝围栏、家具、晾衣、绿植、小猫与轻微动画。
- `src/concert.js`：第4层演出现场、舞台、观众、设备和循环动作。
- `src/projects.js`：项目隔离、自动缩放与放置、局部动画、池塘反射。
- `project-source.cjs`：构建时提取原项目源码。
- `src/main.js`：正交摄影、像素后期、静态批处理、动态实例和交互。
- `src/props.js`：结构材质、花箱、栏杆等复用细节。
- `shell.html`：原生按钮、滑块与无障碍名称。
- 根目录 `tower-projects-qa.cjs`（`tower-qa.cjs` 为快捷入口）：原文件哈希、三场景循环、725次楼层边界检查、结构与搭建切换、后台暂停、减少动画和四种屏幕布局。

使用 Three.js r180 及其 MIT 许可的后期模块，许可嵌入 HTML。石材使用 Poly Haven Rock 04 的颜色、凹凸和粗糙度贴图（Rob Tuytel，CC0），其余纹理由本地 Canvas 生成。三个石材贴图均内嵌 HTML，没有运行时网络请求或 CDN 依赖。静态细节按可见性分组合并，运动部件实例化；切换到其他项目后停止渲染。


## 整楼审查

修正楼梯交接平台重复与屋顶到达平台缺少护栏的问题。池塘反射相机同时包含原人物动态网格和局部照明层，解决主画面实例化后倒影遗漏的问题。框架可继续与楼层模式组合查看。搭建结束后回到全景的状态检查通过，仅合并重复的控件刷新。

本地 tower-building-review.cjs 检查十一块唯一平台、五扇楼梯侧铁门与平台对接、屋顶护栏、人物反射、六个可选层、搭建完成状态、单次滚动只切一层，拖动旋转但不切层。tower-projects-qa.cjs 检查725个楼层边界样本、十二秒循环、原文件哈希、后台暂停、减少动画及四种屏幕布局。审查记录见 previews/tower-building-review.json。

## 05F 温室农场

新温室层放在演出层上方，原生活屋顶完整保留并上移6.4。使用 ?scene=tower&floor=greenhouse 查看；当前楼体有五个场景层和一个屋顶层。

六座拱形温室各有金属拱肋、纵向拉杆、门框、透明覆盖膜与通风扇。棚内两排种植床共180株叶菜和番茄，通道设浇水与收获人物，前侧有货箱、推车及装菜的蓝色小货车，后侧设双水箱、水管、泵柜和蓝色工具棚；围网与低矮绿植包围场地，电线轻微下垂。

地面使用自然农田泥土、深色土垄、细碎土粒与踩踏/车辙纹理，不使用地砖或大理石纹路。仅新层的梁柱、楼板外沿和侧墙使用与屋顶相同的米灰水泥色（底色#d8d0b9，材质色#e5dfcf），31块不规则苔藓贴在墙面和梁柱表面。其余楼层材质保持不变。

人物以固定站位弯腰、浇水和搬菜，棚内叶片轻摆，风扇转动，统一十二秒循环。独立随机种子避免影响旧场景；透明棚面单独绘制，静态框架与作物参与原有合批。原场景文件及原屋顶源代码校验保持不变。

## 与1F统一比例

温室层以1F篮球层的两名站立成人的实际三维包围盒平均身高为尺度参考（约0.7633世界单位）。工作人员未校正时约0.8755，因此温室、作物、人物、货箱、货车、水箱、围栏与设备共同缩放为原来的约87.19%，保持内部比例和站位关系。泥土地面保持完整楼层尺寸，建筑框架、贴壁苔藓、相机和其余场景均保持原状。工作人员在十二秒动作循环中的身高与参考差异保持在3%以内。


## 自由旋转视角

左键或单指拖动支持360度水平环绕，以及5–75度的俯仰调节，保留正交投影和阻尼。滚轮仍逐层切换，切层保留用户旋转角度；双击画面恢复当前楼层默认视角，全景按钮或Home回到完整楼体默认构图。画面可通过Tab聚焦，左右方向键水平旋转，Shift加上下方向键调节俯角，上下方向键继续切层。减少动态效果时，旋转随直接操作更新并在操作结束后停止渲染。只改查看交互，模型、场景比例、材质与动画内容保持不变。
